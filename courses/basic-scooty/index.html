01Course details

Your road to riding solo

4 phases, one at a time. The pace follows your progress.

Scooty basics→Control & survival skills→Balance & low-speed control→Road & practical skills
Class 1–2
  1. 01
    Usually class 1–2
    Phase 01

    Scooty basics

    • Accelerator & brake
    • Engine start / stop
    • Correct sitting posture
    • Handle & body position
    • Basic movement
    • Holding & handling the scooty
    • Taking it off the stand
    • Putting it on the stand safely

    GoalUnderstand the vehicle before riding independently.

  2. 02
    Usually class 2–5
    Phase 02

    Control & survival skills

    • Accelerator control
    • Brake control
    • Start & stop
    • Slow-speed movement
    • Body-weight control
    • Basic visual awareness
    • Situation-based control
    • Basic survival skills

    GoalControl the scooty and respond to basic riding situations.

  3. 03
    Usually class 6–12
    Phase 03

    Balance & low-speed control

    • Feet-off-ground balance
    • 10–50 metre balance practice
    • Gradually longer distances
    • Both feet fully up
    • Low-speed control
    • Body-weight movement
    • Visual focus
    • Straight-line control

    GoalDevelop stable, consistent two-wheeler balance. The number of classes depends on your progress.

  4. 04
    Usually class 12–15
    Phase 04

    Road & practical skills

    • Left & right turns
    • Indicator usage
    • Horn usage
    • Road crossing
    • Lane changing
    • Road positioning
    • Braking + turning + acceleration

    GoalMove from basic balance to practical riding confidence.

Can I learn without knowing how to ride a cycle?

Yes. This course starts from the very basics, with balance practice before road riding.

How long is each class?

Each class is 30 minutes. The course has 15 classes.

What if I need more time for balance?

The pace follows your progress. Phase 3 (balance) usually takes classes 6–12, depending on the learner.

Where can I take this course?

At all 7 centres: Tollygunge, Rabindra Sarovar, Patuli, New Town, Barasat, Sodepur and Howrah.
